SumikakuGapCutter (スミカク用スキマ型抜きツール)

Glyphs 3 / 4 向けのパス上下関係（オーバー／アンダー）表現のための自動型抜きフィルタプラグインです．
文字デザインにおいて，重なり合うストロークやパス同士に視覚的な「前後関係」を持たせる際，上層パスの周囲に一定幅の「透明な縁取り（マージン・隙間）」を設け，下層パスを自動的に切り抜きます．

※ 本プラグインのコードおよび設計プロトタイプは，Gemini 2.0 Flash Thinking Experimental（Gemini Spark）との対話・コード生成を通じて開発されました．
※ 本プラグインは 845Fonts「スミカク」制作時に使用した個人用ツールを一般公開用に調整したものです．一部至らない点や使いづらい部分があるかと思いますが，あらかじめご了承ください．

==================================================
主な機能と特徴

1. 自動型抜き（オフセット・ブーリアン処理）:
・選択した上層パスの輪郭を外側に一定幅（Margin）だけ自動拡張し，下層のパスに対して非破壊的・高精度にブーリアン差分（型抜き）処理を実行します．
・ストロークの端点は平頭（Butt）で固定処理され，スキマを生成します．
2.パスの独立性・構造維持:
・下層のパスを1本ずつ個別に切り抜く処理を行うため，近接・接触している別々のストローク同士が勝手に結合・一体化（Remove Overlap）されるトラブルを防ぎます．
3.編集ビュー:
・編集ビュー上で切り抜き結果をリアルタイムに確認できるプレビュー機能を搭載しています．
・スペースキー長押しで Glyphs 本体の黒塗りプレビューを表示したまま，ダイアログ操作やキーボードでの数値微調整が可能です．
・Enter / Return キーでの確定，Escape キーでの安全なキャンセル，Cmd + Z による1ステップでの完全 Undo に対応しています．

インストール手順と動作確認方法

1. 一度 Glyphs を終了します．
2. SumikakuGapCutterフォルダ内の SumikakuGapCutter.glyphsFilter をダブルクリックしてインストールします（またはプラグインフォルダ内の既存プラグインを置き換えます）．
3. Glyphs を再起動します．
4. 任意のグリフの編集画面を開き，重なり合う複数のパスを描画します．
5. 手前に残したいパス（上層）を選択ツールで選択した状態で，メニューバーの「フィルタ」>「SumikakuGapCutter...」を実行します．
6. 設定ダイアログが表示され，背面のパスが指定したマージン幅で切り抜かれるプレビューが表示されることを確認してください．
